# 氛围音（放松区）

四个场景各一个循环音频，**文件名必须是下面这四个**，路径已经写在 `site.config.ts` 的
`lounge.scenes` 里，换文件不用改代码：

| 文件名 | 场景 | 现在是什么 |
|---|---|---|
| `rain.mp3` | 雨夜 | 合成：带通白噪声（雨）+ 低频闷响 |
| `waves.mp3` | 海浪 | 合成：棕噪声做 10 秒一次的涌浪 + 泡沫声 |
| `fire.mp3` | 篝火 | 合成：低频轰声 + 噪声门蹦出的噼啪 |
| `space.mp3` | 深空 | 合成：55/82.5/110/165Hz 正弦持续音 + 缓慢起伏的低通噪声 |

## 当前这四个文件是怎么来的

由 `scripts/generate-ambient.sh` 用 ffmpeg 合成（`bash scripts/generate-ambient.sh` 可重跑）。
选合成而不是找素材，是因为它同时满足三件事：**授权干净**（没有任何第三方素材）、
**能无缝循环**（所有调制周期都是 10 秒，90 秒整除，循环点前后是连续的）、
**体积小**（每个 1.2MB）。四段统一压到 **−23 LUFS**，所以切换场景不会忽大忽小。

## 想换成真实录音

直接用同名 mp3 覆盖即可，代码和配置都不用动。挑素材时注意：

- **1–3 分钟、首尾能接上**（首尾音量差太大，循环时会有咔哒声）；
- 112–128kbps mp3 足够，单个文件建议 3MB 以内；
- 四个文件的响度要接近（目标 −23 LUFS 左右），否则切场景会突然变吵；
- 版权：用 CC0 / 公共领域素材（freesound.org 开 CC0 过滤、pixabay.com/sound-effects），
  别用音乐平台下载的歌。

## 两个已知的小事

- mp3 格式本身在文件首尾有编码器补的静音，浏览器循环时**可能**有几十毫秒的缝。
  雨/海浪/篝火这类噪声听不出来；深空那种持续音如果你听到接缝，告诉我换成无缝格式。
- 文件不在时放松区照常能用：背景动画照跑，只是没声音，底部会显示一行提示，
  呼吸圆环退回固定节奏（有声音时它跟着实时音量律动）。
