# 氛围音（放松区）

把循环氛围音放进这个目录，**文件名必须是下面这四个**，放进去就自动生效，
不需要改代码或配置（路径已经写在 `site.config.ts` 的 `lounge.scenes` 里）：

| 文件名 | 场景 | 建议 |
|---|---|---|
| `rain.mp3` | 雨夜 | 中等雨声，不要有雷 |
| `waves.mp3` | 海浪 | 缓慢的拍岸声 |
| `fire.mp3` | 篝火 | 木柴噼啪 |
| `space.mp3` | 深空 | 低频嗡鸣 / 白噪 |

要求：

- **1–3 分钟、首尾能接上**（首尾音量差太大循环时会有咔哒声）；
- 128kbps mp3 足够，单个文件建议 3MB 以内；
- 版权：用 CC0 / 公共领域素材（freesound.org 选 CC0 过滤、pixabay.com/sound-effects），
  别用平台里下载的歌。

文件不在时放松区照常能用：背景动画照跑，只是没有声音，底部会显示一行提示，
呼吸圆环退回固定节奏的呼吸（有声音时它会跟着实际音量律动）。
