# 分工提示词（每个阶段开一个新终端，复制对应提示词发给它）

> 使用方法：在项目文件夹 `个人网页/` 里打开新终端 → 运行 `claude`（建议用 `/model` 选 Opus，动效/设计密集的阶段 1、4 也可以用更强的模型）→ 粘贴对应阶段的提示词。
> 每个阶段做完、你验收满意并 commit 之后，再开下一个终端做下一阶段。**不要两个终端同时改这个项目。**

## 阶段 1：脚手架 + Hello 开场页

```
请先阅读 CLAUDE.md、docs/PLAN.md、docs/进度.md、docs/素材清单.md，然后完成阶段 1，只做阶段 1：

1. 在当前文件夹初始化 Next.js 15 项目（App Router + TypeScript + Tailwind CSS v4），安装 framer-motion、next-intl、gray-matter。保持兼容静态导出。
2. 按 PLAN.md §5 建立黑白设计系统：Tailwind 主题 tokens（颜色、字体、间距）、全局样式、暗色模式基础。
3. 搭好 next-intl 双语框架（/zh 默认，/en 切换），建立文案字典结构。
4. 按 PLAN.md §7 建好 content/ 目录结构和 site.config.ts（社交链接等先用占位，字段留好）。
5. 实现 Hello 开场页：**用浏览器打开 docs/design/Intro.dc.html 对照还原**——深空暗色底（径向辉光 + 星点闪烁 + 噪点颗粒 + 暗角）、Logo 居中（用 docs/design/wl-logo.png，反色显示，浮动 + 光泽扫过动画）、上下细分割线划开动画、NAME/SINCE 两侧标注、一句话定位（中英占位）、"向下滚动进入"按钮（四角标框 + 上下浮动）+ "或按 Enter ↵"提示；滚动/回车/点击均触发过渡动画进入 /home（首页先放占位页）；sessionStorage 记住本次已进入，不重复显示；尊重 prefers-reduced-motion。
6. git init，创建 .gitignore，首次 commit；如果我的 gh CLI 可用，问我仓库名和公开/私有后创建 GitHub 仓库并 push。
7. npm run build 确认通过，npm run dev 让我在浏览器验收开场页效果。
完成后更新 docs/进度.md 并 commit。
```

## 阶段 2：主站骨架页面

```
请先阅读 CLAUDE.md、docs/PLAN.md、docs/进度.md、docs/素材清单.md，然后完成阶段 2，只做阶段 2：

2. /home 首页（对照 Main.dc.html 右侧）：衬线大字名字（dcRise stagger 入场）、自我介绍两段（关键词带灰底细下划线链接）、"现在是"板块（读 content/now/，显示更新月份）、"我在做的"（项目精选 2-3 条）、"我写的"（最新文章列表：标题 + 类型标签 + 日期）、页脚"想说点什么就写封邮件"一行。

6. /tools 工具页（对照 Tools.dc.html）：读取 content/tools.json 渲染双列卡片网格（图标 + 名称 + 一句话 + ↗）；图标平时黑白，hover 时亮各自品牌色 + 卡片上浮加深阴影（画板左上角第一张卡即 hover 态）；先按画板里的 8 个工具做占位数据。

8. 页面切换淡入、滚动进入视口 stagger 淡入。所有文案中英双语。完成后逐页与画板并排比对一次，修正明显偏差。
完成后 npm run build 通过、让我浏览器验收、更新 docs/进度.md 并 commit。
```

## 阶段 3：Markdown 博客系统

```
请先阅读 CLAUDE.md、docs/PLAN.md、docs/进度.md，然后完成阶段 3，只做阶段 3：

1. 构建时读取 content/posts/*.md（gray-matter 解析 front-matter：title、title_en、date、type: blog|essay|thought、tags、lang、summary）。
2. /blog 列表页（用浏览器打开 docs/design/BlogContact.dc.html 对照其上半"写字的地方"还原）：标题 + "共 N 篇"引导语；全部/博客/长文/想法标签筛选 + "按时间倒序"标注；条目为日期左列 + 标题（hover 下划线）+ 摘要 + 类型/标签 chips + 阅读时长；年份变化时插入年份分隔行。
3. /blog/[slug] 详情页：markdown 渲染（代码高亮、图片、引用样式符合黑白设计系统）、目录（长文侧边）、上一篇/下一篇。
4. 双语策略：front-matter 的 lang 标记文章语言；只有单语版本的文章在另一语言下也显示（标注原文语言）。
5. 生成 RSS。写 3 篇占位文章（每种 type 一篇）验证效果。
6. 在首页的"最新文章"区接入真实数据。
7. /library 书影音收藏页：读取 content/library/ 渲染（书/影/音三类标签切换，条目含标题/作者/评分/短评，先放几条占位）。
8. ⌘K 命令面板（移动端为搜索图标）：搜文章标题与摘要（构建时生成索引，纯前端）、跳转任意页面、切换语言/暗色模式。样式符合黑白设计系统。
9. giscus 评论与留言板：文章详情页底部挂 giscus 评论组件，/guestbook 页挂独立留言串。需要我的 GitHub 仓库为 public 并开启 Discussions——如果还没开，指导我开通并完成 giscus 授权配置（配置写进 site.config.ts）。giscus 主题定制为黑白并跟随暗色模式。
完成后 npm run build 通过、让我验收、更新 docs/进度.md 并 commit。
```

## 阶段 4：放松区（重点阶段，建议用最强模型）

```
请先阅读 CLAUDE.md、docs/PLAN.md（重点 §6）、docs/进度.md、docs/素材清单.md，然后完成阶段 4，只做阶段 4：

1. /lounge 沉浸模式（**用浏览器打开 docs/design/Lounge.dc.html 对照还原**）：进入时整页淡入暗色氛围，左侧边栏收窄为 64px 图标条（Logo + 图标导航 + 底部竖排"ESC 退出沉浸"；鼠标移到左侧或按 ESC 恢复完整侧栏）；顶部居中弱提示"导航已收起"；画面中心为三层同心呼吸圆环（错相呼吸）+ 衬线场景名（中文 + 英文小字距标注）；圆环随氛围音实际音量呼吸；底部：氛围/音乐/播客三标签 → 场景 chips → 暂停圆钮 + 音量滑杆 + "循环 · 交叉淡入"标注。
2. 氛围场景切换（雨夜/海浪/篝火/深空）：全屏背景用 CSS/canvas 生成（径向辉光 + 噪点颗粒 + 斜纹漂移/粒子，黑白低饱和，禁止大图片），每个场景配循环氛围音。氛围音文件若素材未到位，先从 CC0 音效库（freesound/pixabay）给我下载链接让我确认下载，或放静音占位。
3. 音乐分区（网易云嵌入）：嵌入我的网易云歌单外链播放器 iframe（歌单 id 读 site.config.ts，未提供就用占位说明）。iframe 收进黑白卡片/相框式容器弱化违和感，支持配置多个歌单切换（如"专注"“夜晚"）。
4. 播客分区：一个"播客"标签，嵌入我提供的小宇宙/YouTube 播放列表 iframe（链接未提供就留好嵌入位和说明）。
5. 场景/音量用 localStorage 记住；氛围音交叉淡入淡出、随背景动画同步；呼吸圆环动画随氛围音律动。
6. 移动端可用性：iOS 需用户手势后才能出声，进入页面设计一个"轻点开始"交互；氛围音懒加载。
完成后 npm run build 通过、让我戴上耳机验收、更新 docs/进度.md 并 commit。
```
