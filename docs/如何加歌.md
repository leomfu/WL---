# 怎么给「按心情听」歌单加歌 / 删歌

> 写给站主自己看的，不需要碰代码。对应文件：`scripts/music-chart.txt` → 跑一个命令 →
> `content/music/chart.json`。

## 音源用的是什么

**Apple 官方 30 秒预览**（iTunes Search API），不是网易云直链：

- 免费、不用登录、不用 key。
- 每首自带 30 秒官方试听 + 高清封面 + 一个能听全曲的 Apple Music 链接。
- 试听音频**不下载进仓库**——那是 Apple 自己的 CDN，链接可以随时重新取，直接存在 `content/music/chart.json` 里的 `previewUrl` 字段。封面倒是会下载到本地 `public/images/records/`（跟"我听的"那面墙一个待遇）。

⚠️ **有一个没验证过的地方**：`previewUrl` 指向 `audio-ssl.itunes.apple.com`。写这份数据的机器挂着代理，测出来直链能通（HTTP 200），但**没条件验证国内网络不挂代理时能不能直连这个域名**。如果上线后发现某些访客听不到试听，大概率是这个——页面这边已经按"某首可能没有 previewUrl / 播不出来"设计，不会因为一首放不出来就整块坏掉。

## 加一首歌 / 删一首歌

1. 打开 `scripts/music-chart.txt`，找到对应的场景（`## 场景key | 中文名 / English名` 这一行开头的一段）。
2. **加歌**：另起一行，格式 `歌名 - 歌手`。比如：

   ```
   稻香 - 周杰伦
   ```

   如果这首歌不是你确定想放的、只是先占个位置，行尾加一个 `?`：

   ```
   稻香 - 周杰伦 ?
   ```

   加了 `?` 的歌在 `chart.json` 里会带 `"placeholder": true`——这个字段只是给你自己看的元数据，
   唱片页不会把它标出来给访客看，纯粹方便你翻 json 时一眼认出哪些是代选、该换成你真正想放的。

3. **删歌**：直接把那一行删掉或者用 `#` 注释掉。
4. **新增一个场景**：照抄一行 `## key | 中文名 / English名` 当标题，下面跟着这个场景要放的歌。`key` 只能是英文，给代码用；中文名和英文名会显示给访客看。
5. 存盘后跑：

   ```
   npm run chart
   ```

   脚本会逐行去 iTunes 搜索、校验歌手对不对（防止把翻唱/同名歌当成正主），把结果写进 `content/music/chart.json`，封面自动下载到 `public/images/records/`。

## 查不到歌怎么办

终端会打印 `✗ 「歌名 - 歌手」——没找到歌手对得上的版本，跳过`，这首**不会**被塞进 `chart.json`（宁可缺一首，不能塞错一首）。常见原因和对策：

- **歌手名打法不对**：试试用中文全名，或者去掉艺人名里的特殊符号。
- **这首歌真的没在任何一个 Apple Music 商店上架**（比如某些国内网络综艺翻唱、极小众独立音乐人）：换一首，或者接受这首放不进来。
- **同名歌太多、真正想要的那个版本没被选中**：脚本优先选"标题完全对上、不是 Live/Remix/伴奏版"的那条；如果选错了，把 `music-chart.txt` 里那一行的歌手写得更精确一点（比如加上英文名），再跑一次。

## 场景名是我们代拟的

四个场景（深度专注 / 通勤路上 / 番茄钟间隙 / 深夜放空）是照着"你 2026 年刚毕业、在上海做技术支持、每天和 AI 一起干活、有专注区和番茄钟"这个背景猜的，**不是你说过的原话**。想换名字：改 `scripts/music-chart.txt` 里对应的 `## key | 中文名 / English名` 那一行，重跑 `npm run chart` 就行，不用碰代码。想调整每首歌该归哪个场景，把那一行剪切到别的 `##` 标题下面再跑一次。

## 每首歌那句描述是 AI 代拟的，建议你换成自己的话

唱片页唱机右侧现在会显示一句歌曲描述（分类小标 → 歌名 → 艺人 → 专辑 → **描述** → 播放/去平台）。
`chart.json` 里每条的 `desc`（中文）/`descEn`（英文）就是这句话，来源是**代理按歌曲本身可查证的
特征（编曲、乐器、节奏、公认的情绪基调）写的**，不涉及也不该涉及它对你个人的意义——这是你的
个人站，别人代写的感受不能冒充成你自己的。每条都带了一个 `descDraft: true`（页面不显示，
只是给你看的标记），提醒这是初稿。

**建议你把这些换成你自己的话**——一句就够，可以是这首歌对你的意义、你听到的编曲细节、
或者别的任何你想说的。改法：直接编辑 `content/music/chart.json` 里那首歌的 `desc`/`descEn`
两个字段，改完了把 `descDraft` 那行删掉（或者留着也没关系，反正页面不读它）。

⚠️ **重跑 `npm run chart` 不会冲掉你改过的描述**：脚本会先读旧文件，把已经有 `desc`/`descEn`
的条目按「场景 key + 歌曲原始查询词」记下来，写新文件时原样贴回去。但如果你把某首歌从一个场景
剪切到另一个场景（改了它所在的 `##` 标题），或者改了 `music-chart.txt` 里那一行的原文（歌名/歌手
拼法变了），这条「记忆」会对不上，重新生成时那首歌会没有描述——重新写一句就好，损失的只是那一首。
