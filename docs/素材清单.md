## 二、内容（可以持续补充）

- ⬜ **项目列表** → `content/projects/projects.json`（现在是 3 个占位）：
  名称、一句话、技术栈、线上地址、仓库地址、年份、是否 featured（首页只显示 featured 的前 3 个）。
- ⬜ **文章** → `content/posts/*.md`（现在是 3 篇标了 `[示例]` 的占位，**你的第一篇真文章进来后就把它们删掉**）。
  front-matter 字段见 `content/README.md`。
- ⬜ **视频作品** → `content/videos.json`：B 站给 BV 号，YouTube 给视频 id，各配一句介绍。
- ⬜ **工具清单** → `content/tools.json`：现在是画板里那 8 个占位，按你实际在用的增删。

  图标要新增的话在 `src/components/icons/ToolIcon.tsx` 里加一条路径。
- ⬜ **书影音** → `content/library/library.json`：类型（book/movie/album）、标题、作者、评分 1–5、一句短评。

## 三、放松区

- ⬜ **氛围音四个文件** → 放进 `public/audio/ambient/`，**文件名必须是 `rain.mp3` / `waves.mp3` /
  `fire.mp3` / `space.mp3`**，放进去就自动生效，不用改配置。选素材的要求（1–3 分钟、首尾可循环、
  CC0 来源）写在 `public/audio/ambient/README.md` 里。要我帮你从 freesound / pixabay 找下载链接也行。
- ⬜ **网易云歌单** → 歌单 id 填进 `site.config.ts` 的 `lounge.neteasePlaylists`（数组，可放多个，
  放松区会给出切换 chips）。⚠️ 有版权限制的歌（客户端里灰色的）外链播不出来，建好后先自测：
  `https://music.163.com/outchain/player?type=0&id=歌单ID`
- ⬜ **播客** → 小宇宙节目页或 YouTube 播放列表的**嵌入地址**，填进 `lounge.podcastEmbeds`。

## 四、需要你去点几下的（评论 / 部署）

- ⬜ **GitHub 仓库**：本地仓库已有全部提交，还没有远程。
  装 `gh`（`brew install gh` → `gh auth login`）后告诉当班终端，或自己在网页建空仓库后
  `git remote add origin ... && git push -u origin main`。
  ⚠️ 评论和留言板用 giscus，仓库必须是 **public**。
- ⬜ **giscus（文章评论 + 留言板）**：仓库 public 之后，
  ① Settings → General → Features 勾上 **Discussions**；
  ② 到 https://github.com/apps/giscus 把 giscus 装到这个仓库；
  ③ 打开 https://giscus.app 填仓库名，把它给出的 `repo` / `repo-id` / `category` / `category-id`
  填进 `site.config.ts` 的 `giscus` 段。填完评论区自动出现（现在显示的是一行说明文字）。
- ⬜ **部署平台**：Vercel / Cloudflare Pages / GitHub Pages 三选一（我的建议见 docs/进度.md 阶段 5 备注）。
  定了之后把 `site.config.ts` 的 `url` 换成真实域名，再跑 `npm run og` 重生成分享图。
- ⬜ **域名**（可选）：想绑自己的域名就想好一个，部署时一起弄。
- ⬜ **访问统计**（可选）：注册 https://cloud.umami.is（免费版够用），把它给的脚本地址和 website id
  填进 `site.config.ts` 的 `analytics`。不填就完全不加载统计脚本。
