# 素材清单（你需要准备的东西）

> 素材没到位不阻塞开发：开发时先用占位内容，你随时把素材放进对应位置或发给当班终端替换即可。
> 每项到位后把 ⬜ 改成 ✅。

## 必需素材

- ✅ **Logo**：已到位——`docs/design/wl-logo.png`（视觉稿在暗底上用 `filter: invert(1)` 反色显示）。阶段 1 时复制到 `public/logo/` 使用。
- ⬜ **个人信息**（给中文即可，英文版由 Claude 翻译后你过目）：
  - 姓名/昵称（网站上显示的名字）
  - 一句话定位（首页大标题下那句，例如"XX 方向的开发者/创作者"）
  - 个人介绍（About 页，几段话：背景、在做什么、兴趣）
- ⬜ **联系邮箱**：网站上公开展示的邮箱（确认是否用 weiliang99520@gmail.com，还是想用别的公开邮箱）

## 内容素材（可以持续补充）

- ⬜ **项目列表**：每个项目的名称、一两句介绍、链接（线上地址/GitHub 仓库）、可选截图
- ⬜ **已有文章**：markdown 或纯文本都行，Claude 帮你转成规范格式放进 `content/posts/`
- ⬜ **想法/短文**：同上，type 标为 thought

## 放松区素材

- ⬜ **网易云歌单**：在网易云建 1–2 个歌单（如"专注"“夜晚"），用于外链播放器嵌入。⚠️ 有版权限制的歌（客户端里灰色的）外链放不出来——建好后在浏览器打开 `https://music.163.com/outchain/player?type=0&id=歌单ID` 测试一下能播几首，然后把歌单链接给阶段 4 的终端
- ⬜ **氛围音**（雨声/海浪/篝火等，各 1–3 分钟可循环）：可以让 Claude 从 CC0 免费音效库（如 freesound.org、pixabay）帮你找下载链接。→ 放入 `public/audio/ambient/`
- ⬜ **播客播放列表链接**：你常听的播客在小宇宙/YouTube 上的节目或播放列表链接（用于嵌入）
- ⬜ **喜欢的氛围场景**：从"雨夜 / 海浪 / 篝火 / 深空 / 森林"里挑 3–4 个，或提你自己想要的

## 新增功能素材

- ⬜ **视频作品清单**：你想展示在 /videos 页的自己的视频（B站 BV 号或链接、YouTube 链接，各配一句介绍）
- ⬜ **Now 页面初稿**：最近在忙什么、在学什么、在读什么（几句话即可，以后随时更新）
- ⬜ **书影音初始条目**：最近在看/看过的书、电影、专辑各几条，配一句短评和打分（可选）
- ⬜ **工具清单**（/tools 工具页）：你日常在用的软件/服务/硬件，每个一句话说明 + 官网链接。视觉稿里已放了 8 个占位（Claude Code / ChatGPT / VS Code / GitHub / Figma / Notion / Vercel / Spotify），按你的实际情况增删

## 后面才需要的

- ⬜ **GitHub 仓库**：阶段 1 时终端会帮你创建（需要你装好并登录 `gh` CLI，或手动在网页上建）。⚠️ 因为评论/留言板用 giscus，仓库需要设为 **public（公开）** 并开启 **Discussions**（阶段 3 终端会指导你操作）
- ⬜ **域名**（可选）：如果想绑自己的域名，想好域名，部署阶段再买再绑
- ⬜ **部署平台**：阶段 5 再决定（Vercel / Cloudflare Pages / GitHub Pages）
