    `site.config.ts` 在项目根目录，字段留全（社交 / 网易云 / 播客 / giscus / umami），值先占位。
  - Hello 开场页（`src/components/intro/`）：四层质感（辉光 dcGlow / 46 颗星点 dcTwinkle /

    滚动/回车/空格/触摸/点击五种方式进站、过场淡出+微放大+模糊 620ms 后跳 /home。

  **几个实现上的决定（跟视觉稿有出入的地方）**
  - **根路径 `/`**：静态导出没有 middleware 和 redirect()，所以 `src/app/page.tsx` 输出一张
    最小跳转页（meta refresh + `location.replace` + noscript 链接，底色 `#060606` 不闪白），
    跳到 `/zh/`。`src/app/layout.tsx` 因此只 `return children`，真正的 `<html lang>` 骨架
    在 `src/app/[locale]/layout.tsx` 里（lang 要跟着语言走）。
  - **左上角只留了一个语言切换圆钮**，视觉稿上那个「声音」图标没做——开场页本来就没有声音，
    放个点了没反应的按钮不如不放。声音控件留到阶段 4 的放松区。
  - **进入按钮是 `<Link>` 不是 `<button>`**：禁用 JS 也能进站，有 JS 时 preventDefault 拦下来播过场动画。
  - **回访不闪开场页**：`[locale]/page.tsx` 里内联了一小段脚本，在 HTML 解析阶段就读
    sessionStorage 跳走（早于首次绘制）；组件里的 useEffect 是客户端路由跳回来时的兜底。

  **遗留问题 / 给阶段 2 的提醒**
  - **衬线字体还没自托管**。`--font-serif` 目前是 `"Noto Serif SC", "Source Han Serif SC",
    "Songti SC", Georgia, serif` 的回退栈——你的 Mac 上会落到宋体，效果接近视觉稿；
    但 Windows 访客会掉到别的字体。Google Fonts 在国内还被墙，所以正解是阶段 5
    自己子集化思源宋体放 `public/fonts/`。英文 Inter 已经用 `next/font/google` 自托管，没这问题。
  - **首页 `/[locale]/home` 目前是占位页**，阶段 2 换成真正的首页 + 左侧边栏。
    侧边栏建议抽成 `src/components/shell/`，因为除开场页外所有页面都要用。
  - **社交平台图标还没做**。画板里六个平台的 SVG 路径在 `docs/design/_parts.py` 的 `BRAND` 字典里，
    阶段 2 直接抄成 React 组件即可。注意小红书和抖音那两个是我手绘的近似版，
    有条件换成官方 SVG。
  - **GitHub 仓库没建**：这台机器上没装 `gh` CLI。本地 git 仓库已初始化并完成首次提交
    （54 个文件）。要接远程的话：装 `gh`（`brew install gh` 然后 `gh auth login`）后跟当班终端说一声，
    或者自己在网页上建空仓库再 `git remote add origin ... && git push -u origin main`。
    ⚠️ 阶段 3 的 giscus 要求这个仓库是 **public** 并开启 **Discussions**。
  - **`npm audit` 有 3 条 high**，全部来自 Next 15 的传递依赖（postcss、sharp），
    修复方案是升级到 Next 16，跟 CLAUDE.md 的版本锁定冲突，所以没动。
