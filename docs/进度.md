  **几个实现上的决定（跟视觉稿有出入的地方）**
  - **根路径 `/`**：静态导出没有 middleware 和 redirect()，所以 `src/app/page.tsx` 输出一张
    最小跳转页（meta refresh + `location.replace` + noscript 链接，底色 `#060606` 不闪白），
    跳到 `/zh/`。`src/app/layout.tsx` 因此只 `return children`，真正的 `<html lang>` 骨架
    在 `src/app/[locale]/layout.tsx` 里（lang 要跟着语言走）。
  - **左上角只留了一个语言切换圆钮**，视觉稿上那个「声音」图标没做——开场页本来就没有声音，
    放个点了没反应的按钮不如不放。声音控件留到阶段 4 的放松区。
  - **进入按钮是 `<Link>` 不是 `<button>`**：禁用 JS 也能进站，有 JS 时 preventDefault 拦下来播过场动画。
  - **回访不闪开场页**：`[locale]/page.tsx` 里内联了一小段脚本，在 HTML 解析阶段就读
    sessionStorage 跳走（早于首次绘制）；组件里的 useEffect 是客户端路由跳回来时的兜底。

### 放松区第三层重做：Spotify 嵌入 → 时刻表，并新增番茄钟（2026-08-29）

**起因**：用户在 weiliang.dev 上看到音乐层里一整块白色错误页（Chrome 自己的
「网址可能暂时无法连接」），因为大陆连不上 open.spotify.com。先做了一版可达性探测 +
说明卡兜底（commit 9730265），但用户看了之后要求**根本上不要嵌入**。

**查证结论（别再走回头路）**：想用站内自己的 `<audio>` 播放，就必须有能直接下载的音频直链，
而正版流媒体在授权层面就不给：
- **Spotify Web Playback SDK**：能自定义界面，但要求**每个听众**都有 Premium 并登录你的站，
  内核仍是他们的播放器，大陆照样不通；
- **Apple MusicKit JS**：$99/年开发者账号 + JWT（最长 6 个月）+ 每个听众要 Apple Music 订阅；
- **YouTube IFrame API**：可以藏起 iframe 自建界面，但条款限制外观改动，大陆也不通。
三条都不是「不用嵌入」，只是更麻烦的嵌入。

**网易云直链对华语流行基本无效（实测）**：`song/media/outer/url` 的规则是「网易云能免费试听的
才有直链」。拿张震岳、周杰伦各 10 首实测：张震岳 0/10；周杰伦看着中了 8 首，
**查歌手后发现原唱一首都没有** —— 全是翻唱、假名上传的 remix（`周杰伦-/Montagem`）、
或搜岔的同名歌。真实数字 **0/20**。所以「扩充我在听那一组」这条路对他的口味是死的，
现有 9 首能放是因为那些是没有版权限制的老歌/独立音乐。

**做了什么**：
- 删掉 `SpotifyEmbed.tsx` 和所有 Spotify 嵌入；`site.config.ts` 的
  `spotifyPlaylists` + `podcastEmbeds` 合并成 **`departures`**（一行一个去处，加行即可扩展）。
- 「播客」层 → **「时刻表」层**（`Departures.tsx`）：中心一块走真实时间的站台钟
  （时/分/秒针 + 等宽数字读数），下面是外链列表。理由：这一层的作用就是**离开这个网站**，
  时刻表既是「时间的表格」又是「从这里去哪儿」，和它的处境严丝合缝。
  和音乐层形成对照 —— 那边的指针走「歌的时间」，这边走「现实的时间」。
- 新增 **番茄钟层**（`PomodoroDial.tsx` + `usePomodoro.ts`），和音乐层同一张钟面，
  转满一圈 = 这一段走完。弧线画**剩余**（与音乐层的「已播进度」相反，是故意的）。
  - 状态存的是**绝对结束时刻 `endsAt`**，剩余时间由 `Date.now()` 现算 ——
    后台标签页降频、电脑睡眠都不会少算。**不要改成每 tick 减一秒。**
  - 状态放在 `LoungeStage`（不是番茄钟组件里），切层照走；整个序列化进 localStorage，刷新不丢。
  - 只在阶段结束时更新一次 React 状态，走针和数字用 ref 写 DOM，不带着呼吸圆环一起每秒重画。
  - 结束提示音用 WebAudio 现合成两声（不引入音频文件），可开关，存 localStorage。
  - 跑着时把剩余时间写进标签页标题。
- 抽出 `dial.tsx` 共用表盘几何（刻度/指针/盘心/clock），音乐层、番茄钟、站台钟三处共用。
- 音乐层顺带变干净：选择器从两簇缩回一簇「我在听 9 │ 常驻 4」。
- **氛围音行为改了**：原来切走就停，现在只有**音乐层**会掐掉氛围音，
  番茄钟层和时刻表层让雨声接着放 —— 一边下雨一边专注本来就该这样。
