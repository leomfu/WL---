## 问题详情

### 【建议修】×1

#### src/app/[locale]/(site)/home/page.tsx : 100

**问题描述**  
项目列表中的分隔符 `" —— "` 硬编码在 JSX 中，在英文版本会显示为中文排版符号，不符合英文排版习惯。

**当前代码**
```jsx
{label}
{" —— "}    // 硬编码
{desc}
```

**建议修法**  
将分隔符提取到 messages 中（中文用 ` —— `，英文用 ` · ` 或 ` - `），或使用条件语句根据语言选择：
```jsx
{label}
{locale === "zh" ? " —— " : " · "}
{desc}
```

**影响范围**  
- 英文版本的首页「我在做的」板块（3 个项目卡片）
