我是伟良，人在上海。计算机网络专业，2026 年刚毕业——念的是网络，不是编程出身。

我每天大部分时间都在跟 AI 一起干活，但不是拿它聊天。我用它**读**：看不完的资料丢给它，让它按我写好的规则通读、写摘要、把概念之间的关系连起来，还要定期回头检查有没有前后矛盾——这样学过的东西不会学完就忘。我用它**做**：脑子里冒出来的想法，我讲人话，它落成能跑的代码，做完我自己一行行看懂再上线。我还用它**啃英语**：直接读一手的英文文章，卡住的地方让它把语境和隐含意思一并翻出来，而不是丢给翻译软件。

手上主要的几件：**Claude Code** 是主力，写代码、跑我那套知识库规则都靠它；**Obsidian** 装知识、**Notion** 记事；**ChatGPT** 拿来做日常问答和交叉验证——同一个问题问两家，答案打架的地方往往就是我还没搞懂的地方；剩下 **VS Code + GitHub + Vercel**，负责把东西写出来、存住、发出去。

我不觉得会用 AI 是什么本事，真正难的是**判断它给的东西对不对**——所以我把过程原样记在这里：学明白的讲成人话，没学明白的照实说，工具只推我自己花钱用过的。

想看我用这些东西做出了什么，翻 [项目](/projects)；最近在忙什么在 [现在](/now)；想明白的事写在 [文章](/blog) 里；全套工具清单在 [工具](/tools)。
